# CRP_Prem

Algorithms for **CRP-Prem** (pre-marshalling).

Current implementations:
- `heuristic/caserta_voss_2009_cm/` — Corridor Method style heuristic.
- `heuristic/lee_chao_2009_nsip/` — neighborhood search + solver-assisted IP reduction (Gurobi).
- `heuristic/huang_lin_2012_labelling/` — Huang-Lin labelling heuristic (Type-A) using R/W stack labels and buffer-driven stack completion/deconstruction.
- `heuristic/bortfeldt_forster_2012_tree_search/` — Bortfeldt-Forster (EJOR 2012) heuristic tree search with BG/BB/GG/GB move classification, Proposition 1 lower bound and compound-move branching (normal max-length BG / extra non-BG prefixes) with 3-rule per-move filtering; V0-V4 ablation switches exposed.
- `heuristic/wang_jin_lim_2015_target_guided/` — Wang-Jin-Lim (Omega 2015) target-guided heuristic (TGH): fixes containers one at a time via giant moves (Case 1/2 nslot-based sub-scenarios) and 5-priority relocation with fulfillment; guarantees termination; CPMP-with-dummy-stack (CPMPDS) variant exposed via `has_dummy_stack`.
- `heuristic/wang_jin_zhang_lim_2017_fbh/` — Wang-Jin-Zhang-Lim (EJOR 2017) feasibility-based heuristic (FBH): six-tuple lexicographic task selection gated by a necessary surplus-vector state-feasibility check, container/state stability, and proactive dead-end avoidance (pre-extreme/tier-protection), with the full STAP move-accomplishment machinery (alpha, EvalMove, Interim/InterimFull, BiSender/BiReceiver, internal I1-I3 / external E1-E4 cases).
- `heuristic/exposito_melian_moreno_2012_lpfh/` — Lowest Priority First Heuristic (LPFH) with multistart and paper-inspired instance generator.
- `heuristic/jovanovic_tuba_voss_2015_multiheuristic/` — deterministic multi-heuristic extension of LPFH's four-stage skeleton (block/destination/relocation/filling heuristics, 2x2x3x4=48-combination search), with formalized deadlock avoidance (Eq.7-9) and move-sequence correction (Eq.10-11).
- `heuristic/tus_rendl_raidl_2014_2d_pmp/` — one-paper bundle containing 2D-LPFH, 2D-Pilot and 2D-MMAS.
- `exact/solver/van_brink_2014_branch_price/` — branch-and-price style exact solver scaffold with Gurobi master model.
- `exact/search/tierney_voss_2016_rcpmp/` — robust pre-marshalling exact-search embedding (relaxation-guided IDA*). No MIP solver required.
- `exact/solver/boge_goerigk_knust_2020_robust_premarshalling/` — robust PMP with adjacent-swap uncertainty budget (`delta`), theorem-based existence checks, and Gurobi upper-bound robust MIP embedding.
- `exact/search/parreno_torres_alvarez_valdes_ruiz_tierney_2020_cpmpct/` — crane-time minimization CPMPCT embedding with acceleration-aware crane-time model and exact B&B backend. No MIP solver required (the `mip_model.py` backend entrypoint routes to the same solver-free B&B engine).
- `exact/solver/lee_hsu_2007_network_flow_ip/` — Lee-Hsu (COR 2007) time-expanded multi-commodity network-flow IP (Gurobi), with the paper's own multi-move relaxation (Eq.33-34) + 2/3-cycle-breaking constraints (Eq.31-32), an ascending time-horizon search driver, and a post-processing pass (Sec. 5) that reconstructs an executable move sequence (breaking any residual long cycle via a spare-stack reroute). Exact final layout (Eq.27) and one-type-per-stack (Eq.28) extensions exposed as config toggles.
- `exact/solver/de_melo_silva_2018/` — de Melo da Silva, Toulouse & Wolfler Calvo (EJOR 2018) PMPm1: time-indexed 0/1 MIP (Gurobi) over x/y/z bay-state and movement variables, with the paper's Section 3.2 LIFO (Eq.15-18) and cross-stack flow (Eq.20-22) strengthening constraints on by default. The time horizon T is sized from a from-scratch reimplementation of the paper's own Section 3.3 greedy heuristic (a single solve at T=heuristic value suffices since T only needs to be a valid upper bound, unlike Lee-Hsu's ascending search). Exact final layout (Eq.6) and sorted final layout (Eq.7, default) exposed as mutually exclusive options. This is the PMP quarter of the paper; its BRP/r-BRP formulations (Sec. 3.4-3.7) are embedded independently under CRP-U/CRP-R/CRP-D.
- `exact/solver/parreno_torres_alvarez_valdes_ruiz_2019_ips_models/` — Parreno-Torres, Alvarez-Valdes & Ruiz (EJOR 274, 2019) **IPS6**, the paper's own best-performing model among its eight IP/IPS variants: time-indexed 0/1 MIP (Gurobi) over x (bay state) and split w/z (move-origin / move-destination) variables, constraints (26)-(38) including LIFO (Eq.33), a two-consecutive-occupied-tiers strengthening (Eq.34), and transitive-move / same-priority symmetry breaking across consecutive segments (Eq.35-36, default on). Sized via the paper's own Section 6 **ascending iterative T-search**: start at T = (Section 3 "blocking containers" lower bound) + 1 time points; the first T for which Gurobi returns a feasible solution is, by construction, already optimal — no upper-bound heuristic needed, unlike Lee-Hsu (2007) or de Melo da Silva et al. (2018). The four Section 8 final-layout extensions (adjacent-stack balance, no empty/full stacks, height-stability bonus, same-priority-stacking bonus) are exposed as independent, off-by-default config toggles; each is provably incapable of changing the optimal move count. Fully independent from `de_melo_silva_2018/` (different 2018 EJOR paper) and `exact/search/parreno_torres_alvarez_valdes_ruiz_tierney_2020_cpmpct/` (a later, different 2020 paper by an overlapping author list with a crane-time objective).
- `exact/search/tanaka_tierney_2018_idbb/` — Tanaka & Tierney (EJOR 264, 2018) iterative-deepening branch-and-bound (IDBB): vendors the authors' own public C release (`vendor/pmp-1.02/`, compiled lazily on first use) rather than reimplementing the search from scratch, since the algorithm's performance is inseparable from its low-level lower-bound/dominance-rule details — the Bortfeldt & Forster lower bound with the paper's IBF1/IBF2 tightenings and `TYPE1` unrelated/transitive/same-group dominance pruning, all on by default in the vendored source. No MIP solver required. Cross-validated to agree exactly with `lee_hsu_2007_network_flow_ip/`, `de_melo_silva_2018/` and `parreno_torres_alvarez_valdes_ruiz_2019_ips_models/` on identical small instances. Fully independent from those Gurobi-based embeddings and from `exact/search/parreno_torres_alvarez_valdes_ruiz_tierney_2020_cpmpct/`'s branch-and-bound (a *later*, different 2019/2020 paper by an overlapping author list that builds on this 2018 IDBB but is not what is vendored here).
- `exact/search/tierney_pacino_voss_2017_astar_idastar/` — Tierney, Pacino & Voß (FSMJ 29(2), 2017) exact A* (Algorithm 1) and IDA* (Algorithm 2) pre-marshalling search, pure Python (no vendored code, unlike `tanaka_tierney_2018_idbb/`, since the paper does not publish source). Implements the paper's own EMO lower bound (Section 4.3, an independent re-derivation of the Bortfeldt & Forster 2012 supply/demand bound also used by `tanaka_tierney_2018_idbb/`) with the parent-clamp fix for its lack of heuristic consistency, all four Section 5 branching/symmetry-breaking rule families (move reversal prevention; unrelated-move and transitive-move avoidance, each in directly-successive and successive variants with a configurable `<`/`>` direction; empty-stack symmetry breaking) and A*'s Section 4.4 state memoization + two-stage tie breaking. No MIP/CP solver required. Verified: the EMO bound provably dominates the paper's baseline "direct" bound on cross-check instances; A* and IDA* agree with each other and with `lee_hsu_2007_network_flow_ip/`, `de_melo_silva_2018/`, `parreno_torres_alvarez_valdes_ruiz_2019_ips_models/` and `tanaka_tierney_2018_idbb/` on optimal move counts; 72 branching-rule/bound/direction ablation combinations all agree on the same optimum (the rules are pruning-only and never change optimality).
- `evolutionary/gheith_eltawil_harraz_2015_vclga/` — variable-length GA for CPMP (single-point crossover + 4 mutation types).
- `evolutionary/hottung_tierney_2016_brkga/` — BRKGA with dual backend: native Python decoder and embedded vendor C# source (`vendor/eusorpb-brkga-cpmp`) callable via `backend=vendor/auto`.
