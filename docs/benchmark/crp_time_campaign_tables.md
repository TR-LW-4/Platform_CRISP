# CRP-Time final campaign: Azari, Jovanović, López-Plata under f2, f2vert and the practice preset

Generated by `docs/benchmark/make_campaign_tables.py` from the campaign `docs/validation/data/final_campaign_20261029` (result files in `results/CRP-Time/`); every file is checked to be the campaign's result of its instance.

- **Campaign:** commit `b1e3b12`, Python 3.11.16, archive time 2026-10-29T17:24:22; machine AMD64 Family 25 Model 117 Stepping 2, AuthenticAMD, 16 logical CPUs, Windows-10-10.0.26300-SP0.
- **Runs:** `docs/benchmark/campaign.py`, the web worker of a Workbench batch job, one instance at a time; every saved plan replayed by `campaign.py check` (restricted BRP, H = T + 2, f2, f2vert and the crane time with acceleration recomputed).
- **Instances:** Caserta, 40 per class.
- **Time models (s):** f2: stack_s_per_stack 1.2, pickup_place_s 30, empty_vertical_s_per_tier 2.59, loaded_vertical_s_per_tier 5.18, outside_height 1.5; f2vert: stack_s_per_stack 1.2, pickup_place_s 30, empty_vertical_s_per_tier 2.59, loaded_vertical_s_per_tier 5.18, outside_height 1.5; f2vert (practice parameters): stack_s_per_stack 2.328, pickup_place_s 30, empty_vertical_s_per_tier 1.727, loaded_vertical_s_per_tier 3.455, outside_height 1.5.
- **Algorithm parameters:** Azari et al. (2017) CSUM: gbh_time_limit_s 3, csum_time_limit_s 5; Jovanović et al. (2019) ACO: n_iterations 5000, n_ants 10, q0 0.9, rho 0.1, phi 0.9, max_moves 10, max_const_iter 100; López-Plata et al. (2019) A∗-Based Heuristic: theta 40, lam 500, node_budget 1e+07, rho 300, kappa 2, mu 5, tau 3, time_limit_sec 600.
- **Metrics:** the optimised objective first, then the other crane-time value of the same plan (no f2 for the practice preset). The crane time with acceleration is evaluated only, never optimised. Relocations are counted, not optimised. runtime_s is the algorithm's own time, from reading the bay to its final plan.
- **Not reported:** `crane_time_rmgc`, stored in every result file, is the legacy RMGC model and not part of this phase.
- **Format:** mean ± standard deviation (n − 1) over the 40 instances; runtime_s with 3 decimals below 10 s, 1 decimal above. Time limit hit: López-Plata instances that reached the 600 s limit (step 2); node budget hit: López-Plata instances whose step 1 reached the node budget; Jovanović has neither.
