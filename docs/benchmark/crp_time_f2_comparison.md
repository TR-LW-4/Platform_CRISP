# CRP-Time comparison under f2: Azari, Jovanović, López-Plata

Generated by `docs/benchmark/make_table.py` from the result files in `results/CRP-Time/` and `jobs.jsonl` of the web runs; every cell is recomputed from the result files after writing.

- **Objective:** f2 (crane time with constant pick-up/place-down effort, Voß & Schwarze 2019) is optimised; f2vert is reported from the same runs (the platform evaluates the final plan under both). Relocations are measured, not optimised. Restricted BRP, H = T + 2 (set per instance by the Caserta loader; the `max_tiers` 3 in the `prob_config` of the result files is the unused form value), CRISP time defaults (ts 1.2 s, tpp 30 s).
- **Instances:** Caserta, all 40 instances per class. Seed 0.
- **Runs:** web jobs through `/api/jobs` (the Workbench path), strictly one after another, one instance at a time in one worker process. Azari and López-Plata: overnight run, code `0fc9a87`, 2026-10-05 22:22:59 – 2026-10-06 11:28:22. Jovanović: rerun with the same driver, code `babbdcb`, 2026-10-10 21:41:15 – 2026-10-10 22:04:51. Machine: AMD Ryzen 7 8700F 8-Core Processor, Python 3.11.16, Windows 11 (10.0.26300). runtime_s is the wall clock of `train()` per instance.
- **Jovanović's lower bound:** since `0cb0f50` Jovanović uses the valid lower bound LB_f, eq. 44 without the ts per non-well-located container (Wei's decision; deviation from the paper, `docs/validation/jovanovic_2019.md` §3.3). Its overnight results with the literal eq. 44 are in the separate table below, for comparison only.
- **Time budgets:** Azari: GBH 3 s + CSUM 5 s (wall-clock limits of the paper's method, defaults). Jovanović: 5000 ACO iterations (defaults). López-Plata: paper parameters (ρ 300, λ 500, θ 40, κ 2, µ 5, τ 3, node budget 10⁷) with `time_limit_sec` 600, checked before step 2 and after every completed partial solution (L32); greedy and step 1 are not interrupted.
- **OPT:** the exact rBRP optimum under f2 per instance (A* over bay states, restricted BRP, H = T + 2, ts 1.2 s, tpp 30 s; `docs/validation/jovanovic_2019.md`, "Checks on the O_v difference"). All three algorithms use the restricted rule, so OPT is a lower bound for each of them. Its class means equal the O_f,30 column of Table 5 in Jovanović et al. (2019). Not computed for 5×7 and 6×10.
- **Gap:** mean over the 40 instances of the per-instance gap f2 − OPT, in s and in % of that instance's OPT. Optimal: instances with |f2 − OPT| ≤ 1e-06 s; their gap counts as 0 (float sums in a different order). No instance lies below OPT.
- **Format:** mean ± standard deviation (n − 1) over the 40 instances; runtime_s with 3 decimals below 10 s, 1 decimal above. Limit hit: López-Plata instances that reached the 600 s limit; Jovanović has no wall-clock limit.
